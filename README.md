# spotify-cli
Ever since I migrated from macOS to a fedora-hyprland setup, installing stuff has been hard. _very hard_. one of those apps that annoyingly, fedora does not have in `dnf`, is spotify. I dont want to use the web version because i cant download music there, and i dont want to use their official client because electron, RAM bloat, all of that stuff — so i decided to make a small cli in python for it. you can contribute if you'd like to :)
## how to contribute
always use PRs and use the following guidelines
- `patch:` for small fixes
- `feature:` for new features
- `release:` for software-breaking changes
### make your PRs small
Please make them easy to review and commit small changes.
## that's it!
thanks for contributing!
